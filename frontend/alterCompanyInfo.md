# Company information

## Site settings

Edit `src/data/constants.js` to change:

- Phone, email, location, and opening hours
- Navigation and footer links
- Tax rate and shipping cost

These values affect storefront content and checkout pricing. Refresh the frontend after editing.

## Page content

- Home content: `src/pages/Home.jsx`
- About content: `src/pages/About.jsx`
- Header and navigation: `src/components/layout/Header.jsx`
- Footer: `src/components/layout/Footer.jsx`

## Hero floating spices

Edit `src/components/ui/FloatingSpices.jsx` and add PNG assets under `public/images/floating/`.
